# Solution 04: Erdős–Rényi Random Network Modelling of Pyruvate-Associated Reactions

## 1. Solution Overview

This solution selects the reactions associated with pyruvate, builds a reaction-node network in which reactions are linked through shared metabolites, and compares it with Erdős–Rényi random graphs that have the same number of nodes and the same expected number of edges.

The biological reaction-node projection and the random graph are two different objects. The first is derived from reaction data, and the second is generated by the model G(N, p) and used only as a reference.

The script follows five stages:

1. Reaction loading.
2. Reaction-node network construction and pyruvate-associated selection.
3. Erdős–Rényi realizations and network statistics.
4. Degree distribution comparison.
5. Visualization.

## 3. Computational Methodology

### Stage 1: Reaction Loading

**Library:** Pandas

The input table has `reaction_id`, `substrates` and `products` (multiple metabolites separated by `;`). Duplicate reaction IDs are removed and counted. Each reaction is stored as the set of metabolites on both sides. Reaction direction is not used for linking, because shared-metabolite connections are undirected in this analysis.

### Stage 2: Reaction-Node Network Construction

**Library:** NetworkX

Two reactions are connected by an undirected edge if they share at least one linking metabolite. Linking metabolites are all metabolites except currency metabolites (`CURRENCY`, matched without compartment suffix). The shared metabolites are stored on each edge.

**Pyruvate-associated reactions.** Seed reactions are those that contain a pyruvate identifier (`PYRUVATE_IDS`) as substrate or product. The analysed network contains the seeds and all reactions within `DEPTH` steps of a seed in the full reaction projection, computed with a multi-source shortest-path search. This definition is needed for two reasons:

- A reaction such as acetyl-CoA → citrate does not contain pyruvate but belongs to its metabolic neighbourhood.
- If pyruvate links reactions (`PYRUVATE_LINKS = True`), all seeds share pyruvate and form a clique. With `PYRUVATE_LINKS = False`, pyruvate does not create links, and seeds are connected only through other metabolites.

`DEPTH` and `PYRUVATE_LINKS` therefore define the reaction-connectivity definition and must be documented with any result.

### Stage 3: Erdős–Rényi Realizations and Statistics

**Library:** NetworkX, NumPy, Pandas

With N reaction nodes and L edges in the reference network, the connection probability for an undirected simple graph without self-loops is

p = 2L / [N(N − 1)]

and the expected number of random edges is E[L_random] = pN(N − 1)/2. The script generates `N_RANDOM` graphs with `gnp_random_graph(N, p, seed = SEED + i)`. Fixed seeds make the realizations reproducible. Each realization can have a different number of edges.

For the reference and for every random graph the script calculates:

| Statistic | Definition |
|---|---|
| Edges | Number of links |
| Mean and maximum degree | k = number of linked reaction nodes |
| Average clustering | Mean of C(i) = 2E(i) / [k(i)(k(i) − 1)]; nodes with k < 2 contribute 0 |
| Connected components | Number of components |
| Largest component size | Nodes in the largest component |
| Isolated nodes | Nodes with k = 0 |
| Average path length | Mean shortest-path distance, calculated within the largest connected component only |

For each statistic, the table lists the observed value, the random mean and standard deviation, and an empirical two-sided p-value:

p = (1 + number of random values with |x − mean| ≥ |observed − mean|) / (N_RANDOM + 1)

This is a Monte Carlo comparison with the G(N, p) null model. It tests deviation from that model, not a biological mechanism.

### Stage 4: Degree Distribution Comparison

**Library:** Pandas

P(k) = N(k) / N is calculated for the reference network and averaged over all random graphs (degrees absent from a graph count as 0). Both are drawn in the same panel.

### Stage 5: Visualization

**Library:** Matplotlib, NetworkX

A single PNG shows three panels: the pyruvate reaction-node network, the first random realization and the degree distributions. Layouts use a fixed seed.

| Output | Interpretation |

## 6. Assumptions and Limitations

1. The reaction-node projection creates a clique for each shared metabolite. High clustering compared with G(N, p) is therefore expected from the construction itself and is not evidence of biological organization by itself.
2. Results depend on `DEPTH`, on whether pyruvate links reactions, and on which metabolites are treated as currency.
3. A projection to reaction nodes loses multi-substrate and multi-product information. The metabolite-network topology from Problem 03 is a different object.
4. Small networks give noisy comparisons. Path-length results are limited to largest components, which may have different sizes in the two networks.
5. The Erdős–Rényi graph matches only N and expected L. A degree-preserving model, as in Problem 03, is a more demanding reference.
6. The empirical p-values depend on `N_RANDOM` and are not corrected for the several statistics that are compared.
7. Reaction directionality, stoichiometry, enzymes and thermodynamics are not considered. A shared metabolite is a topological link, not evidence that a pathway is feasible.
